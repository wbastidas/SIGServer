Manual de instalación y uso

Consulta y análisis de redes eléctricas sobre ArcGIS Server

Una plataforma web modular que se instala sobre IIS, se configura con archivos JSON y consume únicamente los servicios de mapas de su propio ArcGIS Server — sin licencias adicionales.

ArcGIS Maps SDK · web components React + TypeScript + Vite Calcite Design System IIS · sin AGOL / CDN
01

¿Qué es y qué resuelve?

Una idea general antes de instalar.

El visor permite buscar, filtrar, medir, dibujar, seleccionar, imprimir y consultar información geográfica de redes eléctricas directamente sobre la cartografía publicada por su ArcGIS Server. Toda la parametrización vive en archivos de texto (JSON), por lo que puede adaptarse sin reprogramar.

Solo ArcGIS Server

No depende de ArcGIS Online ni de Portal. Los mapas salen de sus propios servicios.

Configurable por JSON

URLs, capas, campos, búsquedas y popups se editan sin recompilar la aplicación.

Despliegue en IIS

Se publica como sitio estático. Assets locales: funciona sin internet salvo su servidor.

Responsivo

Escritorio, tablet y móvil, con modo claro y oscuro.

02

Instalación en Windows

Del entorno de prueba a la publicación en IIS.

A · Probar en su equipo (desarrollo)

Requiere Node.js LTS 18 o 20. En la carpeta del proyecto:

npm install
npm run dev     :: abre http://localhost:5173 — entre con admin / admin

B · Publicar en producción (IIS)

Instale IIS y el módulo URL Rewrite

Active Internet Information Services (Contenido estático) y añada el módulo «URL Rewrite». Opcional: «ARR» si usará proxy al backend.

Compile la aplicación

Ejecute npm run build. Se genera la carpeta dist\ con todo lo necesario (incluidos los assets del SDK, sin CDN).

Copie dist\ al sitio

Por ejemplo a C:\inetpub\wwwroot\sigserver, asegurándose de incluir el archivo web.config.

Cree el sitio en IIS Manager

«Agregar sitio web» → apunte la ruta física a esa carpeta y use un enlace HTTPS con su certificado.

Verifique

Abra https://su-servidor/: debe aparecer el login. Ingrese admin / admin y confirme que carga el mapa.

El web.config ya trae configurado el fallback SPA, los tipos MIME, la compresión y las cabeceras de seguridad. No necesita ajustarlo a mano.
CORS: si el navegador bloquea las peticiones al ArcGIS Server, habilite el origen del visor en el servidor o publique ambos bajo el mismo dominio.
03

Configuración

Todo lo que cambia entre despliegues está en config\.

Edite los archivos de public\config\ (o dist\config\ tras compilar). Los principales campos de app-config.json:

CampoQué controla
basemapUrl / basemapTypeURL del mapa base y si es tiled (caché, rápido) o dynamic.
operationalServiceUrlServicio de red (CNELEPN/MapServer).
spatialReferenceWkidSistema de referencia del mapa (p. ej. 32717).
geometryServiceUrlGeometryServer on-prem — evita depender de AGOL en reproyecciones.
visibleLayerIdsCapas encendidas al arrancar.
print.printServiceUrlServicio de impresión (GPServer) para generar PDF/PNG.
auth.arcgisServerSecuredtrue si los servicios exigen token (activa el backend/token broker).

Para añadir una búsqueda, agregue un objeto en searches.json; para cambiar el contenido de un popup, edite popups.json. En ambos casos basta recargar el navegador — sin recompilar.

05

Herramientas

Cada ícono de la barra izquierda abre uno de estos paneles.

Buscar
RF-SRC
  1. Elija el tipo de búsqueda.
  2. Escriba el texto (parcial, sin distinguir mayúsculas).
  3. Pulse Buscar; clic en un resultado → zoom, resalta y abre su popup.
Capas y leyenda
RF-LYR
  1. Casillas para encender/apagar capas.
  2. Control de opacidad por capa.
  3. Leyenda con la simbología visible.
Mapa base
§3.2
  1. Interruptor de visibilidad del mapa base.
  2. Control de opacidad.
Filtros
RF-FIL
  1. Elija la capa / campo (p. ej. ALIMENTADORID).
  2. Marque uno o varios valores.
  3. Aplicar muestra solo esos; Limpiar restaura.
Selección
RF-SEL
  1. Modo Clic, Rectángulo o Polígono.
  2. Los resultados salen en el panel bajo el mapa, agrupados por capa.
  3. Marque casillas → se resaltan en el mapa; clic en la fila navega a ella.
  4. CSV exporta con coordenadas; Terminar vuelve a identificar.
Tabla de atributos
RF-SEL-02
  1. Panel acoplado bajo el mapa, redimensionable, con dos pestañas.
  2. Elija la capa y el alcance: solo lo visible o ver todo.
  3. Filtre con una expresión SQL, p. ej. ALIMENTADORID = 'A1'.
Dibujo
RF-DRW
  1. Elija la forma y dibuje sobre el mapa.
  2. Puede mover, editar y borrar.
  3. No interfiere con la consulta ni la selección.
Medición
RF-MSR
  1. Distancia: puntos sucesivos, doble clic para terminar.
  2. Área: dibuje un polígono.
  3. Limpiar borra el resultado.
Ir a XY / LatLong
RF-GOTO
  1. Elija el sistema de referencia de entrada.
  2. Escriba X/Y o Lat/Long.
  3. Ir centra y marca; Lat/Long se reproyecta solo.
Imprimir
RF-PRT
  1. Elija plantilla, formato (PDF/PNG/JPG), título y escala.
  2. Genere el mapa con simbología y leyenda.
  3. Descargue el archivo resultante.
06

Identificar y Street View

La información de cada elemento.

Al hacer clic sobre el mapa se identifican todos los elementos bajo ese punto, de todas las capas encendidas, en una sola ventana: use las flechas para recorrerlos y ver el poste, el transformador y la luminaria que coinciden en el mismo sitio. Cada uno indica de qué capa procede, muestra los atributos configurados, los registros relacionados y, si está habilitado, un botón Street View.

Atributos y relacionados

Campos con alias, orden y formato definidos en popups.json, más los registros vinculados.

Street View

Sin clave de Google se abre en una ventana emergente del navegador, y se reutiliza la misma al elegir otro punto. Un muñeco en el mapa marca la ubicación que se está viendo y desaparece al cerrarla.
